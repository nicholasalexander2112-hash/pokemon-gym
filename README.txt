PIXEL QUEST — YES2 TRIPLE TRIAL
=================================
Open index.html in a modern desktop or mobile browser. No dependencies or build commands.

The town intro is the same as the original release. Choose START ADVENTURE to watch the trainer walk to the gym, or EXPLORE MYSELF to walk using WASD/arrows and interact using E/A.

Inside the gym your party is ALWAYS the three people shown in the portraits. Water is 1000138732.jpg; Grass is 1000138731.jpg; Fire is 1000138730.jpg, following the order of your latest message. Tap VIEW PROFILE & STATS to open the details and optionally rename their in-game title. Click CHALLENGE GYM LEADER YES2 to start a true 3v3 turn-based match.

Use QUICK STRIKE to build energy; SIGNATURE at 60 energy; FIRST AID to recover; SWITCH CAPTAIN to rotate your team. Water beats Fire, Grass beats Water, Fire beats Grass. You must defeat all three of YES2's rivals. Party HP persists during each match; restarting a match restores both teams. Badge, wins/losses, and names save in local storage.

GITHUB PAGES
============
Upload the CONTENTS of this pokemon-gym folder to your repository root, including index.html and the assets folder. In Settings → Pages select Deploy from a branch → main → /(root). Changes to image filenames or removing assets will break portraits.

Photos are based on the user uploads, with only the surrounding white margins cropped; original portrait subjects and blue backgrounds are preserved. Only publish with the subjects' permission. Fan-inspired, not affiliated with Nintendo or The Pokémon Company.
